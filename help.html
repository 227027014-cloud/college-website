FREQUENTLY ASKED QUESTIONS
How do I start a security scan?
Open Security Scan from the security operations menu and select Start Security Scan to begin system analysis.
Where can I view detected threats?
Open the Threat Intelligence Center to review detected threats, risk levels and attack pattern information.
How can I check network activity?
Open the Network Monitor to view network traffic, monitored endpoints and network event activity.
Where can I view security reports?
Open Security Reports to view generated reports, security analysis and system protection statistics.
How do I change security settings?
Open Settings to manage monitoring, authentication, notifications and security configuration.
